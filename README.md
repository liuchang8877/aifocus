# aifocus

This repository contains a simple Snake game implemented with `pygame`.

## Requirements
- Python 3
- [pygame](https://www.pygame.org/) library

Install dependencies with:

```bash
pip install pygame
```

## Running

Execute the game with:

```bash
python snake_game.py
```
Use the arrow keys to control the snake. Eat the food blocks to grow longer.
A short beep is generated programmatically when food is eaten.
